This project demonstrates Python environment setup and data analysis using the Iris dataset.

## Dataset

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Tasks Completed
- Python library installation and import
- Dataset loading
- Data exploration
- Data cleaning
- Statistical analysis
- Data visualization

This project helped me understand basic data science concepts and Python data analysis techniques.
